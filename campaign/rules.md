# Правила кампании

## Базовая система
Используется D&D 5e 2024.

## House Rules

### Зелья
Зелье лечения можно выпить как Bonus Action.

### Критические попадания
Используется стандартное правило критического попадания.

### Фланкирование
Не используется.

## Неопределённые ситуации

Если правило не определено однозначно, DM должен:
1. сначала обратиться к ruleset;
2. затем к house rules;
3. при конфликте использовать house rules;
4. не менять уже разрешённый результат задним числом.

## Поведение DM

DM не должен самостоятельно изменять HP, AC,
inventory или другие механические значения.
Для этого используется Engine.
